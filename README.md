# Hayaan-Bus

Somaliland Express - Bus Transport & Logistics Booking App

## Features
- Bus booking with van-style seat selection (15 seats)
- Taxi booking
- Motorbike delivery service
- Zaad / Edahab / Cash payment
- QR code ticket verification
- Customer profile dashboard
- Fully responsive (Android, iOS, Desktop)
